# 実証計画・受け入れ基準

机上調査で決めた方針を「実証済み」とするための検証項目です。
**各項目は実施後に結果へのリンクと日付を追記し、未実施のものを実証済みと表記しないでください。**

| 項目 | 受け入れ基準 | 状態 |
| --- | --- | --- |
| キャッシュ有無でのCI総所要時間 | 同一コミットを各5回以上測定し、中央値と最大値を記録 | 未実施 |
| nextestとcargo testの比較 | 同じ条件で所要時間とテスト件数が一致 | 未実施 |
| 重要関数3件のKani PoC | 探索上限・仮定・実行時間を[証明台帳](proofs.md)に記録 | 1件のみ（`increment`） |
| Miriの対応範囲と実行時間 | 対応・非対応テストの一覧と実行時間を記録 | 未実施 |
| 共有crate変更時の逆依存再検証 | 全体検査のため常に満たす。Workspaceで確認 | 未実施 |
| `Cargo.lock`・toolchain変更で全体検証に戻る | 全体検査のため常に満たす。変更PRで確認 | 未実施 |
| Agentによるテスト削除・CI無効化の阻止 | [Rulesets](rulesets.md)とCODEOWNERSの適用後、削除PRがマージできないことを確認 | 未実施 |
| PRランナーからSecretsへアクセスできない | 外部PRとForkでSecretsが空であることを確認 | 未実施 |

状態は、全項目が基準を満たし再現できた時点で、Notion側のページ状態を「実証済み」へ変更します。
